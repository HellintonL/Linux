REGRAS BÁSICAS DE ESTRUTURA PARA CRIAR PÁGINAS
===============================================

Este arquivo mostra uma forma simples de pensar e montar páginas usando HTML
e CSS. Ele funciona como um roteiro para criar uma nova página sem começar do
zero todas as vezes.


1. A IDEIA PRINCIPAL
--------------------

HTML é a estrutura da página.
CSS é a aparência da página.

Uma página normalmente possui uma estrutura parecida, mas o conteúdo e a
organização podem mudar. É possível reutilizar a base e trocar nomes, textos,
cores, tamanhos e áreas.

Isso é parecido com construir casas: todas podem ter portas, paredes e janelas,
mas cada uma pode ter tamanhos, cores e cômodos diferentes.

Você não está errado ao perceber que existe um padrão. A diferença é que não se
altera somente o texto. Dependendo do objetivo, também é preciso mudar a
estrutura e os estilos.


2. ANTES DE ESCREVER O CÓDIGO
-----------------------------

Primeiro responda estas perguntas:

1. Qual é o objetivo da página?
   Exemplos: portfólio, apresentação pessoal, cadastro, loja ou contato.

2. Quem vai usar a página?
   Exemplos: recrutadores, clientes, alunos ou visitantes em geral.

3. O que precisa aparecer?
   Exemplos: título, imagem, descrição, formulário, botão e links.

4. O que deve acontecer quando a pessoa clicar?
   Exemplos: ir para outra seção, abrir outro arquivo ou enviar uma mensagem.

5. A página será usada no celular?
   A resposta quase sempre deve ser sim, então o layout precisa se adaptar.

Essa preparação evita criar elementos sem saber para que eles servem.


3. ESTRUTURA PADRÃO DE UM ARQUIVO HTML
--------------------------------------

Uma página básica costuma começar assim:

<!DOCTYPE html>
<html lang="pt-BR">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Nome da página</title>
    <link rel="stylesheet" href="estilos.css">
</head>
<body>

    <header>
        <!-- Nome e menu -->
    </header>

    <main>
        <!-- Conteúdo principal -->
    </main>

    <footer>
        <!-- Informações finais -->
    </footer>

</body>
</html>

O que pode ser reutilizado:
- A declaração <!DOCTYPE html>
- A linguagem da página
- O charset para os acentos
- A configuração para celular
- A ligação com o arquivo CSS
- As áreas header, main e footer

O que normalmente muda:
- O título da página
- Os textos
- As seções dentro de main
- Os links
- As classes e os nomes usados
- A quantidade de elementos


4. PARA QUE SERVE CADA ÁREA
---------------------------

<html>
Envolve todo o documento. É como a caixa que contém a página inteira.

<head>
Guarda configurações que o navegador precisa conhecer.

<body>
Guarda tudo que aparece para o visitante.

<header>
Normalmente contém o logo, o nome do site e o menu.

<nav>
Agrupa links de navegação.

<main>
Contém o assunto principal da página.

<section>
Divide o assunto em partes. Uma seção deve ter um objetivo claro.

<div>
Agrupa elementos quando é necessário organizar ou aplicar estilo.

<h1>
É o título principal. Em geral, uma página deve ter um título principal claro.

<h2>
É usado nos títulos das grandes seções.

<h3>
É usado em partes menores dentro de uma seção.

<p>
É usado para textos e explicações.

<a>
É usado para links e também pode receber aparência de botão.

<img>
Mostra uma imagem. Deve possuir alt, que descreve a imagem para pessoas que
usam leitores de tela ou quando a imagem não carrega.

<form>
Agrupa campos usados para receber informações do visitante.

<input>, <textarea> e <button>
Criam campos de preenchimento e botões. Eles são comuns em páginas de cadastro
ou contato.

<footer>
Guarda informações finais, como copyright, contato ou links importantes.


5. COMO ESCOLHER AS SEÇÕES
--------------------------

Não é necessário usar todas as áreas em todas as páginas. Escolha somente as
que fazem sentido para o objetivo.

Página pessoal ou portfólio:
- Início
- Sobre
- Habilidades
- Projetos
- Contato

Página de produto:
- Apresentação do produto
- Benefícios
- Imagens ou detalhes
- Preço
- Botão de compra
- Dúvidas

Página de cadastro:
- Título
- Explicação curta
- Formulário
- Botão de envio
- Mensagem de resultado

Página de artigo:
- Título
- Autor e data
- Imagem principal
- Texto dividido em partes
- Links relacionados

A regra mais importante é: cada seção deve ajudar o visitante a entender ou
realizar alguma coisa.


6. COMO USAR class E id
------------------------

Use class quando vários elementos terão a mesma aparência.

Exemplo:
<div class="card">Projeto 1</div>
<div class="card">Projeto 2</div>

Os dois podem receber a mesma regra:
.card {
    padding: 20px;
}

Use id quando uma área precisa de um nome único.

Exemplo:
<section id="contato">...</section>

Um link pode chegar até ela assim:
<a href="#contato">Contato</a>

Resumo:
class = aparência ou comportamento compartilhado.
id = identificação única, muito útil para links internos.


7. COMO PENSAR NO CSS
---------------------

Para cada elemento, pergunte:

1. Qual deve ser a cor do texto?
2. Qual deve ser a cor do fundo?
3. O elemento precisa de espaço por dentro?
4. Ele precisa de espaço em relação aos vizinhos?
5. Deve ficar em linha ou em coluna?
6. Precisa de borda ou cantos arredondados?
7. O que deve acontecer quando o mouse passar?
8. Como ele deve ficar no celular?

Exemplo de um cartão:

.card {
    background-color: #20202a;
    color: #ffffff;
    padding: 20px;
    margin-bottom: 20px;
    border-radius: 8px;
}

Neste exemplo:
- background-color define o fundo.
- color define a cor do texto.
- padding cria espaço interno.
- margin-bottom separa o cartão do próximo.
- border-radius arredonda os cantos.


8. A DIFERENÇA ENTRE margin E padding
--------------------------------------

Imagine um quadro com uma fotografia:

padding é o espaço entre a fotografia e a moldura.
margin é o espaço entre esse quadro e outros quadros na parede.

Use padding quando o conteúdo estiver encostado na borda do próprio elemento.
Use margin quando elementos diferentes estiverem muito próximos.


9. COMO ORGANIZAR ELEMENTOS
---------------------------

display: flex
É a forma mais prática de colocar elementos lado a lado ou empilhados.

Exemplo:

.menu {
    display: flex;
    gap: 20px;
}

Isso coloca os itens do menu em linha com 20 pixels entre eles.

Para empilhar:

.menu {
    display: flex;
    flex-direction: column;
}

Para distribuir o espaço:

.menu {
    display: flex;
    justify-content: space-between;
}

Para centralizar verticalmente:

.menu {
    display: flex;
    align-items: center;
}

Use gap para criar distâncias entre os elementos. Ele costuma ser mais fácil
de entender do que colocar uma margem diferente em cada item.


10. COMO CRIAR UM MENU
----------------------

HTML:

<header class="cabecalho">
    <h2>Nome do site</h2>
    <nav>
        <a href="#inicio">Início</a>
        <a href="#sobre">Sobre</a>
        <a href="#contato">Contato</a>
    </nav>
</header>

CSS básico:

.cabecalho {
    display: flex;
    justify-content: space-between;
    align-items: center;
    padding: 20px 10%;
}

nav {
    display: flex;
    gap: 20px;
}

O menu funciona porque cada href aponta para um id existente em uma seção.


11. COMO CRIAR UMA SEÇÃO
------------------------

HTML:

<section id="sobre" class="secao">
    <h2>Sobre mim</h2>
    <p>Texto explicando esta parte da página.</p>
</section>

CSS:

.secao {
    padding: 80px 10%;
}

O id permite que um link encontre a seção. A class permite que uma ou várias
seções recebam o mesmo estilo.


12. COMO CRIAR UM CARTÃO
------------------------

HTML:

<div class="card">
    <h3>Nome do item</h3>
    <p>Descrição curta do item.</p>
    <a href="#">Ver mais</a>
</div>

CSS:

.card {
    padding: 25px;
    background-color: #20202a;
    border: 1px solid #444444;
    border-radius: 8px;
}

.card:hover {
    transform: translateY(-5px);
}

O cartão agrupa informações relacionadas. O hover cria uma reação visual para
mostrar que ele pode ser interativo.


13. COMO CRIAR UM BOTÃO COM LINK
--------------------------------

HTML:

<a href="#contato" class="botao">Entrar em contato</a>

CSS:

.botao {
    display: inline-block;
    padding: 12px 20px;
    background-color: #7c5cff;
    color: #ffffff;
    border-radius: 8px;
    text-decoration: none;
}

O HTML decide para onde o botão leva. O CSS faz o link parecer um botão.

Um botão visual não significa necessariamente que existe uma ação complexa.
Para enviar dados, validar informações ou alterar a página automaticamente,
pode ser necessário usar JavaScript e, em alguns casos, um servidor.


14. CORES E IDENTIDADE VISUAL
-----------------------------

Escolha poucas cores com funções claras:

- Uma cor para o fundo principal.
- Uma cor para fundos alternativos.
- Uma cor para o texto principal.
- Uma cor para textos secundários.
- Uma cor de destaque para links e botões.

Não escolha cores apenas porque são bonitas. Verifique também se o texto pode
ser lido sobre o fundo. Texto com pouco contraste fica difícil de enxergar.

As cores podem ser escritas assim:

#000000 = preto.
#ffffff = branco.
#ff0000 = vermelho.

O formato hexadecimal começa com # e usa seis caracteres para representar a
mistura de vermelho, verde e azul.


15. COMO DEIXAR A PÁGINA RESPONSIVA
------------------------------------

Responsivo significa que a página se adapta ao computador e ao celular.

Uma regra básica é:

@media (max-width: 800px) {
    .conteudo {
        flex-direction: column;
    }
}

Fora do media query, o conteúdo pode ficar lado a lado. Em uma tela menor, ele
fica empilhado para não apertar ou ultrapassar a largura da tela.

Também é importante:
- Evitar larguras fixas muito grandes.
- Usar max-width quando um texto não deve ficar largo demais.
- Permitir que links e botões quebrem linha.
- Testar a página em uma janela estreita.
- Conferir se nenhum texto fica escondido ou cortado.


16. ORDEM RECOMENDADA PARA CRIAR UMA NOVA PÁGINA
------------------------------------------------

1. Escolha o objetivo da página.
2. Faça uma lista do conteúdo necessário.
3. Crie o arquivo HTML.
4. Divida o conteúdo em header, main, sections e footer quando fizer sentido.
5. Dê nomes claros para as classes.
6. Crie a estrutura visual principal no CSS.
7. Ajuste cores, fontes e espaçamentos.
8. Organize os elementos com flexbox.
9. Crie os estados hover para links e botões importantes.
10. Adicione a adaptação para telas menores.
11. Abra a página no navegador.
12. Clique em todos os links.
13. Confira a aparência em uma tela pequena.
14. Corrija textos, links quebrados, espaços e elementos cortados.


17. COMO SABER SE UMA PÁGINA ESTÁ BEM ORGANIZADA
------------------------------------------------

Pergunte:

- A pessoa entende o objetivo da página rapidamente?
- Existe um título principal claro?
- As seções estão em uma ordem lógica?
- Os links levam aos lugares corretos?
- Os botões parecem clicáveis?
- O texto tem tamanho e contraste confortáveis?
- A página funciona sem ficar cortada no celular?
- Os nomes das classes ajudam a entender o código?
- Há alguma parte que não tem utilidade para o visitante?
- Os comentários explicam algo importante sem poluir o código?

Uma estrutura boa não é a que possui mais código. É a que organiza o conteúdo
com clareza e permite que outra pessoa entenda e altere o projeto.


18. O QUE É REUTILIZÁVEL E O QUE PODE MUDAR
--------------------------------------------

Pode ser reutilizado:
- A estrutura inicial do HTML.
- As configurações do head.
- A ligação com o CSS.
- O modelo de header e footer.
- Regras de botão, cartão e seção.
- A estrutura de responsividade.

Pode mudar:
- Textos e títulos.
- Quantidade de seções.
- Cores e fontes.
- Ordem dos conteúdos.
- Quantidade de cartões.
- Tipo de navegação.
- Tamanho e posição das imagens.
- Necessidade de formulários ou outros recursos.

O código-base é um ponto de partida, não uma obrigação. Você pode reutilizar a
ideia e modificar o que não combina com a nova página.


19. QUANDO HTML E CSS NÃO SÃO SUFICIENTES
------------------------------------------

HTML e CSS são suficientes para páginas estáticas, ou seja, páginas em que o
conteúdo é exibido e os links levam a outros lugares.

JavaScript pode ser necessário quando a página precisa:
- Abrir ou fechar um menu sem recarregar.
- Validar um formulário antes do envio.
- Mudar conteúdo automaticamente.
- Fazer cálculos.
- Criar filtros, carrosséis ou menus interativos.

Um servidor ou banco de dados pode ser necessário quando a página precisa:
- Salvar cadastros.
- Fazer login.
- Guardar mensagens.
- Consultar informações de usuários.
- Processar dados com segurança.

Portanto, HTML e CSS formam a base visual, mas páginas mais avançadas podem
precisar de outras tecnologias.


20. RESUMO MAIS CURTO
---------------------

1. HTML cria e organiza os elementos.
2. CSS define como esses elementos aparecem.
3. class reaproveita estilos.
4. id identifica uma área específica.
5. header, main e footer ajudam a dividir a página.
6. section separa assuntos diferentes.
7. flexbox organiza itens em linha ou coluna.
8. padding cria espaço interno.
9. margin cria espaço externo.
10. hover mostra uma reação ao mouse.
11. @media adapta a página para telas menores.
12. Links funcionam conforme o endereço colocado em href.
13. O conteúdo deve ser planejado antes da aparência.
14. Uma estrutura pode ser reutilizada, mas deve ser adaptada ao objetivo.
15. HTML e CSS bastam para o visual; interações avançadas podem exigir outras
    tecnologias.


CONCLUSÃO
----------

Você consegue montar uma nova página estudando o arquivo de explicação e usando
este roteiro como base. No começo, provavelmente será necessário consultar
alguns exemplos e testar pequenas mudanças. Isso é normal.

O mais importante é aprender a separar as duas perguntas:

"O que precisa existir na página?"      -> HTML
"Como isso deve aparecer?"              -> CSS

Quando a pergunta for "o que deve acontecer depois do clique?", talvez seja
necessário estudar JavaScript ou alguma tecnologia de servidor.
