EXPLICAÇÃO SIMPLES DOS CÓDIGOS HTML E CSS
==========================================

Este arquivo explica, de forma resumida e simples, o que existe nos arquivos
index.html e portfolio.css.

IDEIA GERAL
-----------
O index.html é o conteúdo do site. Ele informa quais textos, títulos, botões,
seções e links devem aparecer.

O portfolio.css é a aparência do site. Ele informa as cores, tamanhos,
espaçamentos, posições, bordas, efeitos ao passar o mouse e o comportamento
em telas menores.

1. COMO HTML E CSS TRABALHAM JUNTOS
-----------------------------------

HTML = é a estrutura e o conteúdo da página. Ele cria títulos, textos, áreas,
botões e links. É como a planta de uma casa: informa quais cômodos existem.

CSS = é a aparência da página. Ele escolhe cores, tamanhos, espaços, posições
e efeitos. É como a decoração e a organização dos cômodos.

O navegador lê o HTML, monta os elementos da página e depois aplica as regras
do CSS que combinam com esses elementos. Por isso, o HTML pode continuar com
o mesmo texto enquanto o CSS muda completamente o visual.

HTML sem CSS ainda funciona, mas fica simples e sem a aparência planejada.
CSS sem HTML não tem elementos para estilizar. Os dois arquivos dependem um do
outro neste projeto.


2. PARTES BÁSICAS DO HTML
-------------------------

<!DOCTYPE html>
O que é: uma declaração sobre o padrão do documento.
Por que existe: ajuda o navegador a interpretar a página corretamente.

<html>
O que é: o elemento que envolve todo o documento.
Por que existe: informa onde começa e termina a página HTML.

lang="pt-BR"
O que é: uma informação sobre o idioma.
Por que existe: ajuda navegadores, mecanismos de busca e leitores de tela a
entenderem que o conteúdo está em português do Brasil.

<head>
O que é: área de configurações e informações da página.
Por que existe: guarda dados que o navegador precisa, mas que não são o
conteúdo principal mostrado na tela.

<body>
O que é: área visível do site.
Por que existe: tudo que o visitante lê ou utiliza fica dentro dela.

<meta charset="UTF-8">
O que é: definição do conjunto de caracteres.
Por que existe: permite mostrar corretamente letras como ã, ç e é.

<meta name="viewport" ...>
O que é: uma configuração para o tamanho da tela.
Por que existe: faz o site usar corretamente a largura de celulares, tablets
e computadores.

<title>
O que é: o título da página.
Por que existe: aparece na aba do navegador e ajuda a identificar o site.

<link rel="stylesheet" href="portfolio.css">
O que é: uma ligação entre arquivos.
Por que existe: importa o CSS para que ele possa estilizar o HTML.

<!-- texto -->
O que é: um comentário.
Por que existe: serve para anotar ou desativar um trecho sem apagá-lo.
Comentários não aparecem na página. No projeto, o PHP está comentado e por
isso não aparece.

4. NOMES QUE LIGAM HTML E CSS
-----------------------------

class="nome"
O que é: um nome que pode ser usado por vários elementos.
Por que existe: permite aplicar o mesmo estilo a elementos parecidos.
Exemplo: todos os elementos com class="card" recebem o visual de cartão.

id="nome"
O que é: um identificador destinado a uma área específica.
Por que existe: os links do menu usam o id para encontrar a seção correta.
Exemplo: href="#projetos" procura id="projetos".
Um id normalmente deve ser único na página.

.nome no CSS
O ponto antes do nome significa "procure uma class".
Exemplo: .card escolhe todos os elementos com class="card".

#nome no CSS
O sinal de número significa "procure um id".
Embora o CSS deste projeto use principalmente classes, o HTML usa ids para
os links internos.

nome do elemento no CSS
Quando o CSS escreve body, header, p ou a sem ponto e sem #, ele escolhe todos
os elementos daquele tipo.

Seletor combinado, como .contato-links a
Escolhe os links que estão dentro da área .contato-links.

Seletor com >, como .card > a
Escolhe apenas um link que é filho direto do cartão, evitando atingir links
mais profundos dentro de outros elementos.


5. COMO UMA REGRA CSS É FORMADA
-------------------------------

.card {
	 padding: 30px;
}

.card = seletor: diz quem receberá a regra.
padding = propriedade: diz qual característica será modificada.
30px = valor: diz quanto espaço será aplicado.
{ } = chaves: marcam o começo e o fim das regras.
; = ponto e vírgula: separa uma propriedade da próxima.

Se duas regras definem a mesma coisa, o navegador considera a combinação de
seletor, ordem e especificidade para decidir qual regra vence. Por isso, uma
regra mais específica, como .contato-links a, pode mudar apenas os links de
contato sem alterar todos os links do site.


6. PROPRIEDADES DE ESPAÇO E TAMANHO
-----------------------------------

margin
O que é: espaço do lado de fora do elemento.
Por que existe: separa um elemento dos elementos vizinhos.

padding
O que é: espaço dentro do elemento, entre o conteúdo e sua borda.
Por que existe: evita que textos e botões fiquem encostados nas bordas.

border
O que é: uma linha ao redor do elemento.
Por que existe: separa visualmente cartões, links e áreas.

border-radius
O que é: arredondamento dos cantos.
Por que existe: deixa botões, cartões e etiquetas com aparência menos rígida.

width e max-width
O que são: largura fixa ou largura máxima.
Por que existem: controlam quanto espaço um elemento pode ocupar. max-width
ajuda textos longos a continuarem confortáveis de ler.

height e min-height
O que são: altura e altura mínima.
Por que existem: garantem que áreas como o início tenham tamanho suficiente.

px
O que é: uma unidade de medida em pixels.
Por que existe: define valores como 80px de altura ou 25px de espaço.

%
O que é: uma medida proporcional ao tamanho disponível.
Por que existe: 10% nas laterais permite que o espaço acompanhe o tamanho da
tela.

vh
O que é: uma unidade baseada na altura da janela. 100vh significa a altura
inteira da área visível.
Por que existe: calc(100vh - 80px) faz a seção inicial ocupar a tela menos o
espaço usado pelo menu de 80 pixels.

calc(...)
O que é: uma conta feita pelo CSS.
Por que existe: combina medidas para chegar a um tamanho que se adapta à tela.


7. CORES E TEXTOS
-----------------

color
Muda a cor do texto.

background-color
Muda a cor do fundo.

#0f0f14, #15151d e outras cores com #
São cores escritas no formato hexadecimal. Cada código representa uma mistura
de vermelho, verde e azul. Neste site, os tons escuros formam o fundo e os
tons roxos e azuis destacam links, títulos e bordas.

font-family
Escolhe a família da fonte. O navegador tenta Arial primeiro e usa Helvetica
ou sans-serif se a primeira opção não estiver disponível.

font-size
Controla o tamanho das letras.

font-weight
Controla a espessura das letras. bold deixa o texto em negrito.

line-height
Controla a distância entre linhas e melhora a leitura dos parágrafos.

text-align
Alinha o texto. O contato usa center para ficar centralizado.

text-decoration
Controla sublinhados e outras decorações. none remove o sublinhado padrão.

text-transform
Muda a forma de exibição das letras. uppercase mostra o texto em maiúsculas.

letter-spacing
Controla o espaço entre letras. O título pequeno das seções usa esse recurso
para ficar mais espaçado.


8. ORGANIZAÇÃO COM FLEXBOX
--------------------------

display: flex
O que é: um modo de organização do CSS.
Por que existe: coloca elementos lado a lado ou em coluna e facilita o
alinhamento sem precisar posicionar tudo manualmente.

flex-direction
Escolhe a direção. row coloca itens em linha; column coloca itens empilhados.

flex: 1
Permite que elementos dividam o espaço disponível de forma equilibrada. É por
isso que texto e habilidades, ou os três cartões, ocupam áreas parecidas.

justify-content
Organiza os itens no sentido principal. space-between coloca o logo e o menu
nas extremidades do cabeçalho; center centraliza os links de contato.

align-items
Alinha os itens no sentido contrário ao principal. center deixa os elementos
alinhados no centro.

gap
Cria uma distância uniforme entre itens, como os links do menu e os cartões.

flex-wrap
Permite que os itens pulem para a próxima linha quando não houver espaço.
No contato, evita que os links saiam da tela em larguras menores.


9. POSIÇÃO E EFEITOS
--------------------

position: sticky
Mantém o cabeçalho acompanhando a rolagem quando ele chega ao topo.

top: 0
Diz que o cabeçalho deve ficar a zero pixels do topo quando estiver preso.

z-index: 10
Define a ordem de sobreposição. O cabeçalho fica acima de elementos que tenham
uma ordem menor.

transition: 0.3s
Faz mudanças de cor, borda ou posição acontecerem suavemente.

:hover
É um estado ativado quando o mouse passa sobre um elemento. No site, muda
links para roxo, levanta botões e eleva cartões para mostrar que são interativos.

transform: translateY(-3px) ou translateY(-8px)
Move o elemento verticalmente para cima sem mudar o lugar dos outros elementos.


10. RESPONSIVIDADE
------------------

Responsividade = capacidade de uma página se adaptar a diferentes telas.
Ela é necessária porque um computador tem muito mais largura que um celular.

@media (max-width: 800px)
O CSS dentro dessa condição só entra em ação quando a janela tem até 800 pixels.

flex-direction: column
Muda conteúdos lado a lado para conteúdos empilhados. Isso facilita a leitura
no celular.

flex-wrap: wrap
Permite que os links que não cabem em uma linha passem para a linha seguinte.

O meta viewport do HTML e o @media do CSS trabalham juntos: o primeiro informa
o tamanho real da tela ao navegador e o segundo muda o layout quando necessário.


11. O QUE ACONTECE QUANDO A PÁGINA ABRE
---------------------------------------

1. O navegador encontra o index.html.
2. Ele identifica o idioma, o título e a configuração para telas menores.
3. Ele lê o conteúdo dentro do body e cria as áreas da página.
4. Ele encontra o link para portfolio.css.
5. Ele aplica as regras gerais e depois as regras específicas de cada class.
6. O visitante vê o menu, o início, o resumo pessoal, os projetos, o contato
	e o rodapé.
7. Quando o visitante clica no menu, o navegador procura o id correspondente.
8. Quando passa o mouse sobre links ou cartões, as regras :hover mostram os
	efeitos visuais.
9. Se a tela tiver até 800 pixels, as regras @media reorganizam o conteúdo.


12. DIFERENÇA ENTRE APARECER E FUNCIONAR
----------------------------------------

Um texto aparecer na tela não significa que ele execute uma função complexa.
Neste projeto, HTML e CSS cuidam da estrutura e do visual. Os links levam a
outras partes ou endereços, mas não existe JavaScript para ações avançadas,
como enviar dados, validar formulários ou salvar cadastros.

O link para cadastro.html só funcionará se esse arquivo existir na mesma pasta.
Os links de WhatsApp, email, GitHub e LinkedIn dependem dos endereços informados
e de o visitante ter acesso à internet.


13. TRADUÇÃO DOS PRINCIPAIS TERMOS
----------------------------------

HTML = linguagem que estrutura a página.
CSS = linguagem que estiliza a página.
tag = marca entre sinais < > que cria ou identifica um elemento HTML.
elemento = uma parte criada pelo HTML, como um título ou parágrafo.
atributo = informação extra dentro da tag, como class, id ou href.
class = nome reutilizável para aplicar estilos.
id = nome único para identificar uma área.
seletor = parte do CSS que escolhe os elementos que receberão regras.
propriedade = característica que o CSS pode modificar.
valor = resultado escolhido para uma propriedade.
regra CSS = seletor junto com suas propriedades e valores.
link = caminho clicável para outra área ou página.
âncora = link que aponta para uma parte da mesma página usando # e um id.
container = elemento usado para agrupar outros elementos.
flexbox = sistema do CSS para organizar elementos em linhas ou colunas.
layout = maneira como os elementos ficam distribuídos na tela.
responsividade = adaptação do layout a diferentes tamanhos de tela.
hover = estado de um elemento enquanto o mouse está sobre ele.
comentário = anotação ignorada pelo navegador e que não aparece para o visitante.
